# Internationalisation

All visible text of the GUI comes from `internal/i18n`, a small UI-agnostic package
(no Fyne import, no dependency). Each language is one JSON file in
[internal/i18n/locales](../internal/i18n/locales), embedded in the binary with `go:embed`.

## File format

Flat object, dotted keys, `{name}` placeholders:

```json
{
  "_meta.name": "Français",
  "_meta.decimal": ",",
  "config.saved": "Cam{slot} enregistrée"
}
```

- `_meta.name`: the language's own name, shown in Configuration > General > Language.
- `_meta.decimal`: decimal mark used by `Translator.Number`.
- `unit.rate.*` and `unit.memory`: units for the status bar (`ko/s`, `Go` in French, `KB/s`, `GB` in English).
- `control.<id>`: label of a standard control id (see `internal/core/catalog.go`).
  Driver-specific controls (`panasonic.*`, `sony.*`) keep the label the driver sends.
- `group.<group>`: title of a control group.

## Using it

```go
tr := i18n.Default().Translator("fr")
tr.T("config.saved", "slot", 3)   // "Cam3 enregistrée"
tr.Number(0.5, 2)                 // "0,50"
tr.Rate(5329.3)                   // "5,2 ko/s"
```

A `Translator` is immutable. The GUI keeps one in its Controller; switching language
swaps the Translator and rebuilds the window content (`gui.App.SetLanguage`).
The GUI-specific mapping from core types to keys (control labels, errors, notices) is in
`internal/gui/texts`.

Lookup order: requested language, then `en`, then the key itself.

## Add a string

1. Add the key to **every** file in `locales/` (same placeholders everywhere).
2. Use it: `tr.T("my.key", "name", value)`.
3. `go test ./internal/i18n/...` checks that every key exists and is non-empty in every
   locale, that placeholders match, and that no value contains an em or en dash.

## Add a language

1. Copy `locales/en.json` to `locales/<code>.json` (for example `de.json`).
2. Set `_meta.name` and `_meta.decimal`, translate the values, keep the keys and placeholders.
3. Run the tests. The language appears in the General tab automatically; nothing else changes.
   Missing keys fall back to English at run time, but the tests require completeness.
